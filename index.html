Terrain tiles

Blender · OpenCV · NumPy
5 scripts · 1,712 lines

Each terrain tile arrives split into many meshes at an unpredictable scale, so tiles can't simply be dropped into one scene. These scripts clean every tile without supervision, then work out how neighbouring tiles fit together from their textures and vertices.

  1. 1

    Batch

    blender_export_gltf.py

    Walks a folder tree of terrain tiles and launches headless Blender once per tile. Output mirrors the input folders, and file size and processing time for every tile go to a CSV.

  2. 2

    Clean and bake

    blender_photogrammetry_headless_processor.py

    Joins the meshes, removes doubles, and doubles or halves the scale until the median tile width lands between 0.6 and 1.4 m. Bakes color onto one 8192 px atlas in Cycles with direct and indirect light off, then exports glTF. Position comes from the east and north offsets in the tile's filename.

  3. 3

    Project top-down

    blender_bake_texture.py

    Renders each tile straight down through one orthographic camera. Ortho scale comes from a meters-per-pixel setting, so every tile shares the same ground resolution. Materials become emission copies for the render and are restored afterwards.

  4. 4

    Align in XY

    blender_align_by_texture.py

    Finds the offset between two top-down textures with FFT phase correlation, checks a ±16 px window at full resolution, then refines to subpixel on the overlap. Writes the move as JSON, plus the diagnostic image used in the demo below.

  5. 5

    Align in Z

    blender_z_align_by_overlap.py

    Uses a quadtree and KD-tree to pair vertices that share an XY position in both meshes, then moves one mesh by the median Z difference. It leaves the mesh alone if it finds fewer than six pairs.

Phase-only normalisation keeps the timing of the texture's detail and throws away its strength, which turns a broad hill of correlation into one sharp spike. On this tile pair the raw version still lands on the right answer with far less margin. Switch off phase_only above and watch the peak ÷ mean figure.

FA = np.fft.fft2(a, s=(H, W))
FB = np.fft.fft2(b, s=(H, W))

R = FA * np.conj(FB)   # cross-spectrum
if phase_only:
    denom = np.abs(R)
    denom[denom < eps] = eps
    R = R / denom       # cross-power spectrum (phase-only)

r = np.fft.ifft2(R)

Crowd conversion

Unreal Engine · Sequencer · Editor Python
5,009 lines · Used on Moana (2026)

Turns animated characters in a Level Sequence into Nanite static meshes that play their animation from baked textures. It runs as a Blueprint-callable library inside the editor, one spawnable binding at a time, and keeps the timing the animator set in Sequencer.

  1. Read. Resolves the skeletal mesh components on a binding and the animation section on each, with start frame, end frame and offset at the sequence's display rate.
  2. Convert. Creates a static mesh per skeletal mesh and animation, with Nanite enabled.
  3. Bake. Fills an AnimToTexture data asset and writes bone position, rotation and weight textures.
  4. Rewire. Duplicates the material instances, switches on the VAT path and sets the maximum World Position Offset displacement.
  5. Rebuild. Assembles a Blueprint, adds it as a spawnable, keys a Frame material parameter per component, and copies the transform and attach tracks across.

USD Transfer

OpenUSD (pxr) · Flask · PyQt5 · paramiko
Exporter: 1,595 lines

Extracts the lights from a shot's USD render manifest into a self-contained package. An artist picks a shot in the browser, the exporter runs on a remote host against the production files, and the result lands in a local folder.

  1. Browser

    Filter, then choose project, sequence, shot, version and format. Selections queue as commands.

  2. Flask app

    Cascading dropdowns load from the file server. Job logs stream back as server-sent events.

  3. Remote host, SSH

    Runs the exporter against the shot's manifest in its own output folder.

  4. Local folder, SFTP

    Downloads the package, then removes the remote copy.

  • Follows sublayers, references, payloads and variant sets from the manifest.
  • Keeps light prims by default. Flags add geometry and referenced prims.
  • Copies dependencies and preserves time samples and root stage metadata.
  • Rewrites asset paths and converts EXR textures to HDR.

Turntable system

Unreal Engine · Movie Render Queue · 1,020 lines
Used on Moana (2026)

Sets up and renders asset turntables from a template. It duplicates a template level and Level Sequence, swaps the asset into the target binding while keeping that binding's sequence properties, and sets a reference object through an Actor Reference track.

Camera defaults sync into Sequencer tracks, and a Python subclass extends a C++ camera bridge. Rendering queues one Movie Render Queue job per sequence from a Movie Graph config.

Camera rail rig

Unreal Engine · Sequencer · 488 lines

Puts actors on a Rig Rail inside a Level Sequence. It builds the spawnables and attach tracks, with a transform actor between rail and object so the object keeps a local offset. It can also reverse a rail, tangents included, and label lengths along the spline.

Timing comes from real-world speed:

t = d ÷ (v ÷ 3.6)   d in m, v in km/h
